# 🎙️ 如何进行学术汇报

大部分内容可参考如何读论文的思考逻辑去进行整理和汇报[如何找论文、读论文](https://dy8q0bnq8y.feishu.cn/wiki/Jwi3wswLNitezskeCOQcqT1rnSe)。

其他需要注意的几个地方：

## 学术汇报的形式

**学术汇报PPT不需要炫酷的动画，但要做到基本的美观**，比如：

1. 中英文字体设置合理、是否统一，例如中文可以用雅黑、幼圆，英文可以用Calibri、Times New Roman等

2. 字号、行间距设置合理，一般**标题字号在32-36之间，正文字号在18-24之间，行间距在1.2-1.5之间**

3. **每页PPT不要出现大段的文字**，每部分文字应该少于3行，除非重要引用，讲PPT的时候不要逐字读文字

4. 重要的部分可以添加高亮颜色、底色框吸引听众注意力

5. 设置关键的目录页、导航页来分解、吸引听众注意力

6. 有一些图片可以让AI来生成，但是要确保内容和逻辑是正确的

7. 更多制作PPT的基本技巧可参考斯坦福的这个报告：[如何做好学术报告](https://www.bilibili.com/video/BV1WF411Y73C/?spm_id_from=333.337.search-card.all.click&vd_source=4deb09ae020d1de21482612e7102fb83)。

## 学术汇报的内容

1. **论文汇报应当选择比较高质量的文章**。AI领域论文非常多，但是很多论文都很水，需要自己做一些价值判断，比如你有没有从这篇文章中学到一些新东西？你分享这篇文章希望大家从这篇文章中学到什么？你后续是否打算follow这篇文章继续往下做？

2. **也可以做一个方向的Tutorial**，比如最近出现了一个与我们研究方向相关、比较火热的词，可以介绍一下相关的工作与发展脉络。

3. **汇报的时候要多站在听众的角度考虑问题，学会换位思考**。尤其是组会的论文分享，要做到讲的内容能让80%以上的人听懂，因此，需要根据受众的范围、知识水平，来决定是否需要添加额外的前置知识。

4. 对于大部分论文，可以参考如下思考：

    1. **针对总体贡献**

        1. **能否用2-3句话总结这篇文章做了什么事情？例如，针对xxx问题，提出了xxx方法，在xxx任务上取得了xxx性能。**

    2. **对于论文动机：**

        1. 这篇文章想解决什么问题？是在做一个很多人研究的问题，还是提出了一个新问题？

        2. 如果是很多人研究过的问题，目前相关的工作有哪些？相关工作可以分成哪几类？本文工作和已有工作相比，核心的优势、创新点是什么？

        3. 如果是一个新问题，那么这个问题是否是真实存在的，还是作者臆想的？什么场景会遇到该问题？解决了这个问题能带来什么好处？有没有简单的方法可以解决这个问题？

    3. **针对论文方法：**

        1. 本文所提方法的主要流程是什么，例如，从算法的输入到输出经过了几个步骤？系统是怎么运行的？包括哪几个模块？

        2. 为什么xxx模块是必须的？为什么xxx技术是可行的？

        3. 每一个模块、技术对于作者想要解决的问题有什么作用？

        4. 在什么场景下该方法适用？什么场景下不适用？

        5. 还有哪些没有做好的地方，如果是你想进一步优化这个方法，你会怎么做？

    4. **针对论文实验：**

        1. 为什么选择这些数据集、对比方法？

        2. 实验设置是否合理、对比是否公平？

        3. 实验结论是否与作者的motivation一致？是否挂羊头卖狗肉？作者claim要解决的问题，有没有解决？结果是否显著?

    5. **尝试总结与思考：**

        1. 把自己当做这篇文章的审稿人，能否给出这篇文章的3个优点和缺点？对于做的不好的地方，你希望作者如何改进，应该做到什么程度？

        2. 你从这篇文章中学到了什么令你感觉新奇的事情？哪怕是论文写作、绘图配色的技巧也很好。

        3. **这篇论文要解决的问题，如果交给你来做，你会怎么做？**

        4. **与这篇论文相关的、您觉得值得研究的一个后续想法是什么？**
